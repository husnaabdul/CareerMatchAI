# CareerMatch AI 🎯

CareerMatch AI is a web application that helps job seekers compare their resumes with job descriptions and track their job applications.

## ✨ Features

- **Resume Analysis:** Upload a resume in PDF format.
- **Skill Matching:** Identify skills that match the job description.
- **Missing Skills:** Find skills that may need improvement.
- **Match Percentage:** Calculate the percentage of required skills found in the resume.
- **Job Application Tracker:** Add, view, update, and delete job applications.
- **Status Tracking:** Track applications as Applied, Interview, Selected, or Rejected.
- **User-Friendly Interface:** Simple and organized web interface.

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- PyMuPDF

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Create and activate a Python virtual environment.
4. Install the required packages:

   ```bash
   python -m pip install flask pymupdf scikit-learn
   ```

5. Start the application:

   ```bash
   python app.py
   ```

6. Open `http://127.0.0.1:5000` in your browser.

## 🎯 Project Goal

The goal of CareerMatch AI is to help job seekers understand how their existing skills align with job requirements and organize their job applications in one place.
